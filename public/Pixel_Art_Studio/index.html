Pixel Art Studio

A full-featured pixel editor powered by Computer Science.

Grid-based Drawing

A responsive HTML5 Canvas mapped perfectly to 16x16, 32x32, or 64x64 grids, converting fluid mouse movements into crisp, aliased pixel art.

Flood Fill Algorithm

The Paint Bucket tool uses a robust Breadth-First Search (BFS) algorithm to traverse the raw `ImageData` Uint8ClampedArray, filling contiguous areas instantly.

PNG Export

When your masterpiece is complete, export it natively using the canvas `.toDataURL()` API to generate a standard image file without a backend.
